# SHIFT_MONITOR: 1998 Guide

Unofficial compact guide site for the HTML5 browser game SHIFT_MONITOR: 1998.

## Pages

- `/` guide hub with CCTV shift planner
- `/play` official itch.io play route
- `/guide` beginner guide
- `/camera-guide` CCTV rotation notes
- `/anomaly-guide` anomaly inspection habits
- `/survival-tips` survival planner and timing tips
- `/updates` source and thin-content safeguards
- `/about`, `/terms`, `/privacy-policy`

## Quality Policy

This is a small SEO experiment, not a text farm. It avoids fake hidden data, keeps a narrow page set, links to the official itch.io page, and includes an original monitor-planning tool.
